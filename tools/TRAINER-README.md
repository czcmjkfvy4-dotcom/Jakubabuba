# Dragon Citadel Trainer

Run `Dragon Citadel Trainer.cmd` from the main desktop folder.

1. Start a single-player VCMI game.
2. Click the game window once.
3. Click a trainer button.

The trainer sends `Tab`, the selected code, and `Enter` to the active game window. The custom `nwcbilladen` code still requires the Dragon Citadel Creator Tools submod and the matching BILLADENC4 runtime.
